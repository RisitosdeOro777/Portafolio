# Actividad 3 — AI Challenge: K-Means y KNN

## Descripción disponible en el portafolio
El proyecto está descrito como una actividad grupal de Machine Learning que explora K-Means y KNN mediante un conjunto de datos sintéticos de estudiantes. El objetivo general indicado es analizar agrupaciones y comparar modelos de clasificación.

## Algoritmos
- **K-Means:** algoritmo de agrupamiento que organiza observaciones en un número definido de grupos según la cercanía entre sus características.
- **KNN (K-Nearest Neighbors):** método supervisado que clasifica una observación a partir de las etiquetas de sus vecinos más cercanos.

## Herramientas mencionadas
Python, NumPy, Pandas, Matplotlib y Scikit-learn.
